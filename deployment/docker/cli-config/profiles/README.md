# Profiles de configuration

Ce dossier contient les profils de configuration pour différents environnements.

## Structure
- `default.yaml` - Configuration par défaut
- `development.yaml` - Pour le développement local
- `staging.yaml` - Pour l'environnement de staging
- `production.yaml` - Pour l'environnement de production

## Utilisation
Pour utiliser un profil spécifique :
```bash
microagents config use-profile development
